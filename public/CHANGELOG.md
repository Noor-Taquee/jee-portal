# JEE Portal v0.4.0 (02-11-2026)

Version 0.4.0 adds Settings and Profile pages, speeds up loading with code splitting, and brings a more polished and accessible experience with improvements across the app.

## Features

- Added code splitting to improve loading performance ([PR #326](https://github.com/Noor-Taquee/jee-portal/pull/326) by @Noor-Taquee).
- Added settings, including general and appearance options ([PR #347](https://github.com/Noor-Taquee/jee-portal/pull/347), [PR #351](https://github.com/Noor-Taquee/jee-portal/pull/351), [PR #355](https://github.com/Noor-Taquee/jee-portal/pull/355), [PR #356](https://github.com/Noor-Taquee/jee-portal/pull/356) by @Noor-Taquee).
- Added profile page and improved password-manager support for changing passwords ([PR #364](https://github.com/Noor-Taquee/jee-portal/pull/364), [PR #366](https://github.com/Noor-Taquee/jee-portal/pull/366) by @Noor-Taquee).
- Added feature page content ([PR #374](https://github.com/Noor-Taquee/jee-portal/pull/374) by @Noor-Taquee).
- Popovers and popups now close automatically when appropriate ([PR #350](https://github.com/Noor-Taquee/jee-portal/pull/350), [PR #358](https://github.com/Noor-Taquee/jee-portal/pull/358) by @Noor-Taquee).

### UI and experience

- Added a footer and refined its styling ([PR #327](https://github.com/Noor-Taquee/jee-portal/pull/327), [PR #354](https://github.com/Noor-Taquee/jee-portal/pull/354) by @Noor-Taquee).
- Improved font loading and readability ([PR #329](https://github.com/Noor-Taquee/jee-portal/pull/329), [PR #331](https://github.com/Noor-Taquee/jee-portal/pull/331), [PR #362](https://github.com/Noor-Taquee/jee-portal/pull/362) by @Noor-Taquee).
- Added a loading animation and refined call-to-action styles ([PR #333](https://github.com/Noor-Taquee/jee-portal/pull/333), [PR #334](https://github.com/Noor-Taquee/jee-portal/pull/334) by @Noor-Taquee).
- Updated the exam selector and scrollbar styles ([PR #335](https://github.com/Noor-Taquee/jee-portal/pull/335), [PR #336](https://github.com/Noor-Taquee/jee-portal/pull/336), [PR #337](https://github.com/Noor-Taquee/jee-portal/pull/337), [PR #338](https://github.com/Noor-Taquee/jee-portal/pull/338) by @Noor-Taquee).
- Refined the home page, 404 page, and documentation sidebar ([PR #339](https://github.com/Noor-Taquee/jee-portal/pull/339), [PR #341](https://github.com/Noor-Taquee/jee-portal/pull/341), [PR #344](https://github.com/Noor-Taquee/jee-portal/pull/344) by @Noor-Taquee).
- Updated the site title ([PR #361](https://github.com/Noor-Taquee/jee-portal/pull/361) by @Noor-Taquee).

### Accessibility

- Improved question-page accessibility and screen-reader behavior; updated link semantics ([PR #357](https://github.com/Noor-Taquee/jee-portal/pull/357), [PR #372](https://github.com/Noor-Taquee/jee-portal/pull/372), [PR #373](https://github.com/Noor-Taquee/jee-portal/pull/373) by @Noor-Taquee).
