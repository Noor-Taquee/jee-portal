# JEE Portal v0.5.0 (23-11-2026)

Version 0.5.0 adds topic and question discovery, user search, account session management, and a more responsive, animated interface.

## Features

- Added practice pages for browsing questions by topic, with subject filtering and topic-specific question lists ([PR #390](https://github.com/Noor-Taquee/jee-portal/pull/390), [PR #423](https://github.com/Noor-Taquee/jee-portal/pull/423) by @Noor-Taquee).
- Added question search and dedicated question pages ([PR #386](https://github.com/Noor-Taquee/jee-portal/pull/386), [PR #389](https://github.com/Noor-Taquee/jee-portal/pull/389) by @Noor-Taquee).
- Added user search and public user profiles ([PR #386](https://github.com/Noor-Taquee/jee-portal/pull/386) by @Noor-Taquee).
- Added active-session information and controls under account settings ([PR #397](https://github.com/Noor-Taquee/jee-portal/pull/397) by @Noor-Taquee).
- Added a changelog page for viewing release history ([PR #375](https://github.com/Noor-Taquee/jee-portal/pull/375) by @Noor-Taquee).
- Added app icons and improved page metadata for search engines and social sharing ([PR #381](https://github.com/Noor-Taquee/jee-portal/pull/381), [PR #376](https://github.com/Noor-Taquee/jee-portal/pull/376), [PR #378](https://github.com/Noor-Taquee/jee-portal/pull/378) by @Noor-Taquee).

### UI and experience

- Added animated, consistently styled popovers and smoother navigation ([PR #428](https://github.com/Noor-Taquee/jee-portal/pull/428), [PR #439](https://github.com/Noor-Taquee/jee-portal/pull/439) by @Noor-Taquee).
- Added reusable question cards and improved their layout ([PR #393](https://github.com/Noor-Taquee/jee-portal/pull/393), [PR #426](https://github.com/Noor-Taquee/jee-portal/pull/426), [PR #433](https://github.com/Noor-Taquee/jee-portal/pull/433) by @Noor-Taquee).
- Improved navigation and settings layouts on mobile and narrow devices ([PR #382](https://github.com/Noor-Taquee/jee-portal/pull/382), [PR #383](https://github.com/Noor-Taquee/jee-portal/pull/383), [PR #411](https://github.com/Noor-Taquee/jee-portal/pull/411) by @Noor-Taquee).
- Updated question-upload and topic-browsing interfaces ([PR #395](https://github.com/Noor-Taquee/jee-portal/pull/395), [PR #417](https://github.com/Noor-Taquee/jee-portal/pull/417), [PR #419](https://github.com/Noor-Taquee/jee-portal/pull/419), [PR #407](https://github.com/Noor-Taquee/jee-portal/pull/407) by @Noor-Taquee).

## Bug fixes

- Fixed popover behavior, question-card headers, and settings-page scrolling ([PR #400](https://github.com/Noor-Taquee/jee-portal/pull/400), [PR #430](https://github.com/Noor-Taquee/jee-portal/pull/430), [PR #438](https://github.com/Noor-Taquee/jee-portal/pull/438) by @Noor-Taquee).
- Fixed registration validation and profile-page metadata ([PR #377](https://github.com/Noor-Taquee/jee-portal/pull/377), [PR #385](https://github.com/Noor-Taquee/jee-portal/pull/385) by @Noor-Taquee).
- Fixed home-page scrolling and duplicate or outdated page metadata ([PR #391](https://github.com/Noor-Taquee/jee-portal/pull/391), [PR #379](https://github.com/Noor-Taquee/jee-portal/pull/379), [PR #399](https://github.com/Noor-Taquee/jee-portal/pull/399) by @Noor-Taquee).
